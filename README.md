## 🛠️ La Norme 42
Tous les fichiers C présents dans ce dépôt respectent la **Norme 42**. Quelques règles clés :
* Pas de boucles `for` (uniquement des `while`).
* Maximum 25 lignes par fonction.
* Maximum 5 fonctions par fichier.
* Déclaration des variables strictement réglementée.
* Interdiction d'utiliser les fonctions de la bibliothèque standard sauf autorisation (réécriture de `ft_putchar`, `ft_putstr`, etc.).
